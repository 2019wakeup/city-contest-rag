# 演示脚本（demo-script）

> 8 步流程 · 总时长约 3–4 分钟 · 供现场演示与录屏旁白使用
> 环境启动见 README「快速开始」（后端 3010 + 前端 5174，打开 http://localhost:5174）
> 主题：默认暗色科技风（Linear 式）；现场投影反光时点左下角「切换到亮色模式」

## 0. 开场（20s）

> "我们做的是「数智选材」——AI 驱动的道路养护决策与沥青材料方案智能推荐系统。行业痛点是：养护决策系统能告诉你'修什么'，但'用什么材料修、为什么、预期效果如何'仍靠工程师经验，从决策到方案要数天到数周。我们把这个过程缩短到一分钟内，并且每一步都有量化依据。"

## 1. 输入养护场景（30s）

- 打开「推荐工作台」，点击「典型案例一键填入」下拉 → 选 **案例一：华南高温重载车辙**。
- 表单自动回填：气候分区 1-4 华南湿热区、PG 76/-10、重交通、ESAL 3000 万、病害=车辙（severe）+推挤、预算 500 万、工期 30 天。
- 讲解："场景全部标准化为结构化标签——气候、荷载、病害、约束，这是后面检索与匹配的钥匙。"

## 2. 生成推荐（10s，点击「生成推荐方案」）

- 六步步进条实时展示：解析 → 映射 → 召回 → 预测 → 排序 → 报告（各步毫秒级）。
- 讲解："整个推荐链路 6 步，耗时毫秒级，而传统做法需要数天到数周。"

## 3. 目标性能与优先级（30s）

- 展示「目标性能与权重」：高温 PG / 低温 PG 的目标值与权重。
- 讲解："第一步先把'修什么'翻译成'要什么性能'。华南高温重载场景，高温抗车辙是最高优先级。权重支持工程师在微调面板调整——人在回路。"

## 4. 推荐结论（30s，KPI hero + 报告位于结果区顶部）

- 展示顶部 **KPI 摘要**：首选方案 + 综合得分（大字号）+ 预期寿命 / LCC / 碳排 三指标。
- 展示「推荐报告」：首选方案结论、8 维雷达图相对优势；**点击报告里的证据角标**（如 k-modifier-002:0）→ 页面自动滚动定位到对应证据原文并高亮。
- 讲解："首先给出结论——首选方案、为什么选它、预期寿命和全生命周期成本是多少。数值全部来自确定性计算，点击角标可以跳转到证据原文。"

## 5. 多方案对比（60s，展开方案卡）

- 方案卡默认只展开第一名，其余折叠为摘要行（材料名+得分）——点开第二名做对比。
- 展开方案 1：沥青品种、级配、改性剂；每个性能预测带**置信区间**；雷达图 8 维（高温/低温/疲劳/水稳/LCC/碳排/预期寿命/施工可行性）。
- 展示「与规范查表基线对比」表。
- 讲解："5 个候选不是拍脑袋——每个都由多目标加权排序（性能×权重+成本碳排约束）得出，且和规范查表基线对比，量化显示提升幅度。"

## 6. 证据链与可解释（45s）

- 在展开的方案卡内点击「证据链」展开：知识条目原文 + 来源（DOI/规范号）+ 相关度。
- 讲解："为什么推荐这个配方？每个结论都可溯源——证据来自我们 42 条材料知识条目、57 条规范条文、142 篇文献题录构建的向量知识库，混合检索（语义+关键词）召回。LLM 只负责组织文案，数值全部确定性计算，不产生幻觉。"

## 7. 微调确认（30s）

- 在微调面板改预算（例如 500→350）→ 「应用并重新推荐」，观察排序变化。
- 讲解："工程师可以微调约束，系统实时重新推荐——这就是'人工微调确认'环节，决策权始终在人。"

## 8. 切换案例 + 知识库（40s）

- 切到「典型案例」页：5 个案例（高温重载 / 寒冷裂缝 / 水损害 / 高RAP再生 / 低噪排水）一键载入。
- 切到「知识库管理」：展示统计（241 个知识块）、检索测试框（输入"车辙 SBS"）、上传入口（企业资料 PDF 可随时入库）。
- 收尾："知识库是可生长的——企业提供新资料可随时上传入库；对接真实性能预测模型后，这套系统可直接嵌入养护决策流程。"

## 附：常见追问与应答

| 追问 | 应答口径 |
|---|---|
| 数据哪来的？ | 公开文献（DOI 逐条标注）+ 8 份现行规范原文 + 公开数据集；模拟数据均有"模拟"角标 |
| 推荐可信吗？ | 金标准回归集 20 条双引擎召回 20/20；5 案例端到端验收；所有数值可溯源 |
| LLM 会乱说吗？ | 数值不经过 LLM；LLM 文案只能引用传入的证据 ID，代码层过滤防编造 |
| 团队信息为何匿名？ | 遵守大赛匿名要求 |
