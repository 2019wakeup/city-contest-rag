### 1.2 每条文献的三道核验

**这是本表与普通"AI 生成的文献清单"的根本区别**——所有题录信息不是凭记忆写的，而是程序回填的：

1. **注册库回填（主）**：以 DOI 调用 Crossref 官方 API（`api.crossref.org/works/<DOI>`），把返回的**标题、作者、期刊、年份**写入表格。也就是说，正表里的题录信息来自出版商向 Crossref 注册的元数据，不是转述。
2. **多途径二次确认（补）**：Crossref 未收录的条目（中国 DOI 体系、arXiv 预印本、部分会议论文、行业标准），依次尝试 `doi.org` 解析落地页标题、**arXiv 官方 API**、以及记录中登记的**来源 URL 页面**，命中才放行。
3. **链接实测**：所有「代码链接」「数据集下载地址」由程序实际发起 HTTP 请求，状态码记录在「链接可用性核查」工作表。GitHub 仓库额外读取星标数与最近推送时间，用于判断是否仍在维护。

**隔离机制**：三道都没过的条目**不进入正表**，集中在「待人工复核」工作表并标注失败原因。宁可表短，不可表假。

### 1.3 明确没有做到的事

诚实标注边界，避免团队误用：

- **JCR/CCF 分区未核实**（见 §0.5）；本次仅核实了部分期刊的影响因子，且来源为第三方汇总站。
- **未逐篇精读全文**。本报告中的**定量数值来自文献摘要与题录信息**，用于说明"方向与量级"，写入说明书或用于设定模型超参数前**必须回查原文**。需要精读的清单见 §6。
- **部分站点在本环境不可达**：`infopave.fhwa.dot.gov`（LTPP 原始下载入口）超时、`zenodo.org` 与 `paperswithcode.com` DNS 解析失败、ScienceDirect/MDPI/T&F 对抓取返回 403。这些不影响 DOI 核验，但相关链接需在浏览器中自行确认（表中已标注）。

## 2. 任务 1：背景知识（直接可用于立项依据与背景章节）

### 2.1 沥青材料体系：答辩时要能说清的参数链

背景写作最容易犯的错是"堆名词"。建议按下面这条**因果链**组织，每一环都有文献支撑：

**原油 → 四组分（SARA）→ 胶体结构 → 针入度/PG 分级 → 改性（掺聚合物/橡胶/添加剂）→ 老化与流变指标 → 路用性能**

- **四组分与胶体结构**：沥青由饱和分、芳香分、胶质、沥青质组成，沥青质含量与聚集状态决定稠度与温度敏感性。这是"为什么掺量不同性能差异大"的化学底层解释，权威综述见 *Materials* 2022（DOI 10.3390/ma15030905）。
- **分级体系**：中国用针入度分级（70#/90#/110# 等）+ 粘度分级；美国 Superpave 用 **PG XX-YY 性能分级**（高温等级抗车辙、低温等级抗开裂）。PG 分级的完整方法学与近年 DSR 车辙因子、BBR、**MSCR** 的发展见 *Construction and Building Materials* 2022 综述（DOI 10.1016/j.conbuildmat.2021.126063）；MSCR 指标 Jnr 与弹性恢复率表征高温抗车辙能力的专门综述见 DOI 10.1016/j.conbuildmat.2020.121320。**这两篇是"参数配置"字段的定义依据。**
- **改性沥青**：SBS 的改性效果取决于相结构（聚合物相是否形成连续网络），影响因素、荧光显微与流变表征方法见 *CBM* 2021 综述（DOI 10.1016/j.conbuildmat.2021.123610）；聚合物改性机理与力学性能规律的 2024 年新综述见 *Cleaner Materials*（DOI 10.1016/j.clema.2024.100255）。橡胶粉（废轮胎）湿法改性的制备工艺、性能与溶胀-降解交互机理见 DOI 10.1016/j.conbuildmat.2022.129168；环氧沥青用于钢桥面等重载场景的固化机理与性能见 DOI 10.1155/2021/3454029；新疆天然岩沥青改性效果见 DOI 10.1016/j.conbuildmat.2017.07.182；双层排水路面用**高粘改性沥青**配比与评价指标见 DOI 10.1016/j.conbuildmat.2020.121893。
- **老化与耐久**：紫外老化机理、室内模拟方法与评价指标的系统综述见 DOI 10.1016/j.conbuildmat.2022.128889。短期 RTFO / 长期 PAV 老化是标准试验链条，试验方法以 JTG 3410-2025 为准。
- **再生与温拌**：再生剂类型、掺量设计与高 RAP 掺量下的性能平衡见 DOI 10.1016/j.jclepro.2023.136994；新旧沥青混融机理与混融度评价见 DOI 10.1016/j.jclepro.2023.136515（**决定了 RAP 掺量的上限约束**）；厂拌乳化沥青冷再生原材料与破乳机理见 DOI 10.1016/j.conbuildmat.2024.137344；温拌技术（有机添加剂/发泡/化学添加剂）降黏机理与减排效益见 DOI 10.1016/j.jclepro.2020.122128。
- **添加剂**：消石灰、胺类、硅烷类三种抗剥落剂对水稳定性、刚度与抗车辙的影响对比见 *Buildings* 2024（DOI 10.3390/buildings14082458）；抗剥落剂对水损害的量化改善见 DOI 10.1016/j.ijadhadh.2017.03.016；玄武岩纤维增强增韧机理与最佳掺量见 DOI 10.3390/ma15196826；木质素纤维与硅藻土改性效果与掺量见 DOI 10.3390/ma12030400。
- **微观机理解释**：分子动力学用于沥青自愈合扩散、集料界面黏附与相容性研究的方法综述见 DOI 10.1016/j.molliq.2022.120363。这一篇的价值在于：当评委质疑"你的模型是不是纯数据拟合"时，可以用它说明**机理约束从哪来**。

> **给背景写作的直接建议**：背景章节不要写成"沥青很复杂"，而要写成"**参数空间与场景需求的匹配是组合爆炸问题**"——基质标号 × 改性剂类型与掺量 × 级配类型 × 助剂 × 工艺温度，量级在 10³ 以上，人工经验无法穷举，这正是 AI 选材的必要性论证。上面每一类材料都提供了"可调参数"，这就是向量库与优化器的变量维度来源。

### 2.2 路面病害与路况指标：模块 A 的输入字段来源

**病害 → 指标 → 处治方向**三者的对应关系，是"场景→性能需求"映射的规则底座：

| 病害类型 | 主要成因 | 关键评价指标 | 处治/选材方向 | 文献 |
|---|---|---|---|---|
| 车辙（失稳型/磨耗型/结构型） | 高温 + 重载 + 渠化交通下沥青混合料抗剪不足 | 车辙深度 RD、动稳定度 DS、RDI | 提高高温 PG、SBS/高模量/抗车辙剂、控制 VV | 10.1515/eng-2022-0463 |
| 自上而下裂缝（纵向/龟裂） | 表面拉应力与老化，常伴轮迹带 | 裂缝率、PCI | 提高低温性能与抗裂、加铺应力吸收层 | 10.3390/app8050774 |
| 反射裂缝 | 基层/旧路面裂缝向上反射 | 裂缝率 | 加铺层抗裂评价、SAMI | 10.1061/(ASCE)MT.1943-5533.0003254 |
| 水损害/剥落 | 水 + 冻融 + 集料-沥青黏附不足 | TSR 冻融劈裂强度比、残留稳定度 | 抗剥落剂（消石灰/胺类）、增粘改性 | 10.1016/j.ijadhadh.2017.03.016；10.3390/buildings14082458 |
| 坑槽 | 水损害 + 荷载 + 局部薄弱 | 破损率 DR、PCI | 冷补/热补材料、封水 | 10.3390/rs14163892 |
| 抗滑不足 | 集料磨光、沥青泛油 | 摆值 BPN、构造深度 | 上面层集料与级配（OGFC/SMA） | 10.1080/10298436.2018.1525489 |

**路况评定指标（中国口径）**：PCI（路面状况指数）、RQI（行驶质量指数）、RDI（车辙深度指数）、SRI（抗滑指数）、DR（破损率）、PSSI（结构强度）及其优/良/中/次/差分级阈值，**权威依据是 JTG 5210-2018**（原 JTG H20-2007 已废止）。这些指标正是模块 A 的输入标签，也是 5 个案例的"现状描述"字段。

**性能衰变预测的总览**见 DOI 10.1155/2022/7783588（对比确定性、概率型与机器学习方法的优缺点与影响参数）；马尔可夫链 + ANN 混合预测高速公路性能衰变见 DOI 10.1007/s11227-020-03329-4。

### 2.3 气候与荷载：把"哪里修"变成可计算输入

这是本课题**最值得在答辩中强调的量化映射环节**，因为你找到了一篇高度对口的文献：

- **机器学习气候分区 + 沥青选型**（宁夏案例）：以机器学习在气候变化情景下做沥青路面气候分区并给出 PG 等级选材结果，见 *International Journal of Transportation Science and Technology* 2025（DOI 10.1016/j.ijtst.2024.10.001）。**这篇几乎就是"气候→材料"选材的现成范式**，模块 A 的方法论可直接对标。
- **气候分区的传统方法**：以 739 个气象站数据、用 ≥20℃ 积温、降水温度指数、降水冰冻指数与极端最低气温指标，提出中国沥青路面气候影响 **8 个一级区、39 个二级区**方案（《交通运输工程学报》2007）。这是中国气候分区字段的权威依据，但**无 DOI**，来源 URL 已登记在表中。
- **空间插值 + 模糊 C 均值聚类**做气候分区的可迁移方法：DOI 10.1080/10298436.2022.2072498。
- **气候变化对车辙的影响**：评估中国各气候区抗车辙能力时空变化、识别高温高风险区，见 *JCLP* 2024（DOI 10.1016/j.jclepro.2024.144016）。可用于论证"气候分区不是静态的、需要动态更新"，是模块 E 反馈闭环的天然理由。
- **交通荷载**：动态荷载纳入轴载谱测定见 DOI 10.1080/14680629.2019.1687006；**渠化交通**与轮迹横向摆动对车辙发展的加速作用见 DOI 10.1080/10298436.2022.2118272（这条支撑"重载车道 vs 一般车道需求不同"的差异化推荐）。

### 2.4 养护决策与全生命周期：把"材料推荐"嵌进决策链

- **路面资产管理系统总纲**：数据采集、性能预测、养护决策优化的技术路线与瓶颈，见 *Automation in Construction* 2020（DOI 10.1016/j.autcon.2020.103336）。**建议作为立项依据的第一篇引用**——它把"决策止步于工法、未打通材料"的行业现状讲清楚了。
- **预防性养护措施的量化效果与时机**：基于 LTPP 长期性能数据评价雾封层、碎石封层、微表处等效果，见 DOI 10.1007/s42947-021-00078-2。这是"措施效果反馈"的证据来源，同时提供了 LTPP 数据入口。
- **路网级养护方案多目标优化**：同时考虑养护资金、路面性能、道路用户与**碳排放**，见 DOI 10.3390/app13158842。**这是模块 D 多维对比（性能/成本/碳排）的直接方法学参照。**
- **LCA/LCCA 方法框架**：边界设定、清单数据与评价指标见 DOI 10.1080/14680629.2023.2278149。写了这一篇，"碳排放"才不是拍脑袋的数字。
- **场景→措施推荐算法**（与模块 B 最接近的方法学）：用多分类机器学习由路网路况数据**预测应采取何种养护措施类型**，替代传统决策树/决策矩阵，见 *RMPD* 2022（DOI 10.1080/14680629.2021.2019091）。**建议作为"场景→方案"推荐的方法学原型**：它做的正是"输入路况、输出措施"，我们把它从"措施"推进到"材料配方"。

## 3. 任务 2：推荐算法与向量知识库怎么建

### 3.1 两条路线，以及为什么必须都做

文献清楚地分成两条互不替代的路线：

| | 路线 A：语义检索（RAG/LLM） | 路线 B：量化关系 + 代理模型 + 优化 |
|---|---|---|
| 输入 | 自然语言场景描述 | 结构化场景参数（PG、ESAL、病害、约束） |
| 中间层 | 向量库 + 知识图谱 + 混合检索 | 材料-性能关系表 + 预测模型 |
| 输出 | 相似案例、条文依据、**推荐理由文本** | **定量候选配方 + 性能预测值 + Pareto 前沿** |
| 能回答 | "为什么这么选""依据哪条规范" | "这个配方的高温性能是多少""成本降多少" |
| 不能回答 | 给不出配方数值与性能预测 | 说不出理由、无法溯源条文 |
| 文献 | GraphRAG 综述（10.1145/3777378）、道路运维知识图谱（10.1016/j.autcon.2025.106733）、桥梁养护知识图谱（10.1016/j.autcon.2024.105634）、KG+CBR 案例检索（10.1371/journal.pone.0294130） | 数据驱动配比反向匹配（10.11896/cldb.24010230）、材料逆向设计选型指南（10.1039/D3MH00039G）、贝叶斯优化（10.1109/JPROC.2015.2494218） |

### 3.4 权重分配与多准则决策（回应赛题点名的"优先级排序"）

### 4.5 建议的"主方法 + 简单基线"（对应分工表第 4、5 项交付）

**主方法（模块 C）**：以 **LightGBM/XGBoost 多输出回归 + SHAP** 为第一版代理模型，特征取"材料组成 + 环境/荷载"（级配、油石比、VV/VMA、PG、改性剂类型与掺量、温度、频率），多任务同时输出车辙、E*、疲劳、TSR、低温指标；以 **Witczak 类机理模型作为对照基线**，并给出 R²/MAE/RMSE 对比表。

**升级路径（时间够再做）**：加入物理约束（PINN 思路，对标 10.1016/j.neunet.2023.12.039）与不确定性输出（分位数回归 / MAPIE 保形预测）。

**简单基线（保证"至少一种可运行"）**：
1. 规范查表/经验公式基线（成分 → 性能的经验回归，如 10.1177/0361198196154000103）；
2. 单指标 XGBoost 基线（只预测车辙或只预测 E*），用于证明多任务/物理约束的增益。

**"打擂台"对照组**（《作战计划》§4.5 已提出，文献支持）：专家经验选型 → 规范查表法 → 单指标 ML → **Vanilla RAG-LLM 直接生成配方**（用于证明"关系表 + 优化 + 预测"比纯 LLM 更可靠、更少幻觉）。
